# transformer-from-scratch
Trying to learn and build a transformer from scratch to understand architecture and important components of it. Experimenting tansformer for better understanding in modern transformers and llm's.

The standard Transformer uses 6*(encoder,decoder) layers.we are going to use 2 layer for learning ,prototype and understanding how the tensors and dimensions flow.

The Dataset is take from: https://www.kaggle.com/datasets/jannesklaas/scifi-stories-text-corpus

For training, testing, and validation we have taken 1% of dataset only and this data set is also used for fine-tuning llm's and transformer's
